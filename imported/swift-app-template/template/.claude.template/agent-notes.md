# Agent Notes — Corrections & Standing Directives

**Read this file at the start of every session before doing work.**

This is an append-only running log of user corrections and standing always/never directives for how to work in this repo.

## Rules for maintaining this file

- Append one line per directive **proactively** (without being asked) whenever the user makes a correction or gives an always/never instruction.
- Newest lines at the bottom.
- One line per entry.
- Never delete or silently edit an existing entry — an untracked change is indistinguishable from a rebase dropping it. Rewrite it **in place**, keeping its date stamp, prefixed with a marker: `(SUPERSEDED <date> — <what changed>.)` when its substance no longer applies, or `(REVISED <date> — <what changed>.)` when you corrected it and it still stands. Never leave both the old and new claim unmarked. `Scripts/check-agent-notes.sh` uses these markers to tell an intentional rewrite from a dropped directive.
